# FD_FishTool

Инструмент для полной автоматизации процесса создания персонажа-рыбки в Autodesk Maya (Python 3). 
Скрипт объединяет этапы риггинга тела и лица, скиннинга, применения анимационных пресетов, настройки файлов для экспорта и валидации сцены.

## 📦 Установка (Для пользователей)

Мы сделали процесс установки максимально простым. Вам не нужно редактировать системные файлы Maya (`userSetup.py`) или прописывать пути вручную.

1. **Скачайте архив** с инструментом (или склонируйте репозиторий).
2. Распакуйте архив в любое удобное для вас место на компьютере (желательно туда, где лежат ваши скрипты, например: `Documents/maya/scripts/`).
   > ⚠️ **Важно:** Убедитесь, что корневая папка называется строго **`FD_FishTool`**. Если вы скачали архив с GitHub, он может называться `FD_FishTool-main` — просто переименуйте папку, убрав `-main`.
3. Откройте Autodesk Maya.
4. Выберите полку (Shelf), на которую хотите установить инструмент (например, *Custom* или *Rigging*).
5. Из проводника Windows (или Finder) захватите файл **`install.py`** и **перетяните (Drag & Drop) его прямо в окно перспективы (Viewport) Maya**.
6. На вашей полке появится новая кнопка с надписью **FISH**. Инструмент готов к работе!

## 🚀 Запуск и использование

- Просто нажмите кнопку **FISH** на полке. 
- Инструмент автоматически проверит наличие старых окон, очистит кэш UI и загрузит нужный интерфейс поверх Maya.
- *Примечание:* Конфигурации путей подтягиваются из файла `data/paths.json`.

## 🛠 Техническая информация (Для разработчиков)

- **Версия Python:** Python 3
- **UI Framework:** PySide2 / PySide6 (зависит от версии Maya)
- **Архитектура:**
  - `main_app.py` — Точка входа в приложение.
  - `install.py` — Drag-and-Drop установщик.
  - `core/` — Логика (риг, физика, экспорт, анимации).
  - `ui/` — Компоненты интерфейса.
  - `data/` — JSON конфиги, пресеты .ma, иконки, маппинги костей (`bone_map.json`, `paths.json` и др.).

Все правки в логику загрузки файлов анимаций (подобно AnimAsist и Studio Library) производятся в `core/anim_manager.py` и `data/animation.txt`.
